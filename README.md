# Grok Lab

Public hub for **Tony Hine** ([Uncle-Gizmo](https://github.com/Uncle-Gizmo))’s work with Grok-family tools.

This repo is an **index**. Product detail lives in the linked pages below. Nothing here contains secrets, private ops, or credentials.

---

## Products

| Product | What it is | Public page |
|---------|------------|-------------|
| **Grok Build (GB)** | Agentic coding / build agent (CLI + ACP) | [grok-build-info](https://github.com/Uncle-Gizmo/grok-build-info) |
| **Grok Bot** | Cursor desktop assistants for ops, GitHub hygiene, and day-to-day agent work | [grok-bot-info](https://github.com/Uncle-Gizmo/grok-bot-info) |
| **Grok Heavy** | Deep research / critique / long-form analysis, often handing off into GB or Bot | [grok-heavy-info](https://github.com/Uncle-Gizmo/grok-heavy-info) |

---

## How they fit together

```text
Grok Heavy ──research & critique──▶ Grok Build (implement)
                 │
                 └──briefs / decisions──▶ Grok Bot (ops, hygiene, monitoring)
```

Private collaboration between agents stays off this hub. Public pages only get **curated, approved** highlights.
